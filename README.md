# BDEngine Mobile

Unofficial Android wrapper for the BDEngine web editor.

## Current MVP

- Opens the official BDEngine editor in an Android WebView
- Forces desktop browser mode
- Keeps cookies and WebView storage so login/session data can persist
- Runs fullscreen without browser chrome
- Locks the app to landscape orientation
- Supports Android back navigation inside the WebView
